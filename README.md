# 学习通防点名工具

> 自动监控学习通课堂中的签到/点名活动，检测到活动后立即自动提交，避免被点名后无响应而被记录缺席。

---

## 功能特性

| 功能 | 状态 |
|------|------|
| 手机号 + 密码登录 | ✅ |
| 自动获取所有课程列表 | ✅ |
| 实时轮询签到/点名活动 | ✅ |
| 普通签到（type 2）自动提交 | ✅ |
| 手势签到（type 3）自动提交 | ✅ |
| 位置签到（type 4）自动提交 | ✅ |
| 二维码签到（type 5）提示手动处理 | ⚠️ |
| 指定只监控部分课程 | ✅ |

---

## 环境要求

- Python 3.10+

---

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 创建配置文件

```bash
cp config.example.json config.json
```

然后编辑 `config.json`，填写你的手机号和密码：

```json
{
    "phone": "138xxxxxxxx",
    "password": "你的密码",
    "interval": 30,
    "courses": [],
    "location": {
        "latitude": "39.9042",
        "longitude": "116.4074",
        "address": "北京市"
    }
}
```

| 字段 | 说明 | 默认值 |
|------|------|--------|
| `phone` | 学习通绑定手机号 | 必填 |
| `password` | 登录密码（明文，程序内部自动 MD5 加密） | 必填 |
| `interval` | 轮询间隔（秒） | `30` |
| `courses` | 只监控的课程名称列表，填 `[]` 表示监控全部 | `[]` |
| `location` | 位置签到坐标（选填），不填则使用默认坐标 | 选填 |

### 3. 运行

```bash
python main.py
```

运行后程序会持续监控，检测到签到活动时自动提交：

```
[✓] 登录成功，欢迎 小韩
[✓] 共获取到 6 门课程
[✓] 开始监控，轮询间隔 30 秒，按 Ctrl+C 退出

  [!] 发现活跃签到活动 [普通签到] activeId=123456789
  [✓] 签到成功！服务器返回：{"result":"1"}
```

按 `Ctrl+C` 退出监控。

## 配置说明

### 只监控部分课程

在 `config.json` 的 `courses` 字段中列出课程名称：

```json
{
    "courses": ["高等数学", "大学英语"]
}
```

### 位置签到坐标

如果你的课程使用位置签到，请在 `config.json` 中添加 `location` 字段，填写你所在学校/上课地点的坐标（可通过百度地图获取）：

```json
{
    "location": {
        "latitude": "30.5728",
        "longitude": "104.0668",
        "address": "四川省成都市"
    }
}
```
